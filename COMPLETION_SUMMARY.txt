  QUICK START
================================================================================

1. Deploy to Vercel
   $ vercel deploy

2. Set Environment Variables
   • NEXT_PUBLIC_SUPABASE_URL
   • NEXT_PUBLIC_SUPABASE_ANON_KEY
   • OPENROUTER_API_KEY
   • CRON_SECRET

3. Visit Dashboard
   https://your-domain.com

4. Add RSS Feeds
   Feeds tab → Add Feed

5. Configure Crons
   Vercel dashboard → Crons → Create 3 jobs

6. Let It Run!
   Automatic processing starts
