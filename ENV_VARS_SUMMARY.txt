PART 3: OAUTH2 ARCHITECTURE
================================================================================

Current Implementation: ✓ Direct Token Storage (NO Callback Route)

Google OAuth2 Flow:
┌─────────────────────────────────────────────────────────┐
│ User manually gets OAuth2 access token                  │
│ (via Google Cloud Console + OAuth Playground)           │
└─────────────────┬───────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────────────────────┐
│ Store access token in:                                  │
│ Supabase → system_config → blogger_api_key              │
└─────────────────┬───────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────────────────────┐
│ API calls use stored token directly:                    │
│ fetch('https://www.googleapis.com/blogger/v3/...',      │
│   {headers: {Authorization: `Bearer ${token}`}})        │
└─────────────────┬───────────────────────────────────────┘
                  ↓
┌─────────────────────────────────────────────────────────┐
│ Create/Publish posts to Blogger                         │
└─────────────────────────────────────────────────────────┘

Redirect URI Status: NOT USED ✓
└─ Why? Manual token storage eliminates need for OAuth callback
└─ No /api/oauth/callback route required
└─ No /auth/callback route required
└─ Simpler deployment, fewer moving parts

PART 4: HOW TO GET BLOGGER ACCESS TOKEN
================================================================================

Step 1: Google Cloud Setup
  └─ Go to: https://console.cloud.google.com
  └─ Create new project
  └─ Search for "Blogger API" → Enable
  └─ Go to Credentials → Create OAuth 2.0 (Desktop app)
  └─ Save: GOOGLE_CLIENT_ID and GOOGLE_CLIENT_SECRET

Step 2: Get Authorization Code
  └─ Go to: https://developers.google.com/oauthplayground
  └─ Step 1: Select scope "Blogger API v3"
  └─ Step 1: Select "https://www.googleapis.com/auth/blogger"
  └─ Step 2: Exchange auth code → Copy "Authorization code"

Step 3: Exchange for Access Token
  └─ Run this curl command:
     curl -X POST https://oauth2.googleapis.com/token \
       -d "client_id=YOUR_CLIENT_ID" \
       -d "client_secret=YOUR_CLIENT_SECRET" \
       -d "code=AUTHORIZATION_CODE" \
       -d "grant_type=authorization_code" \
       -d "redirect_uri=urn:ietf:wg:oauth:2.0:oob"

  └─ Response will include:
     {
       "access_token": "ya29.a0AfH6SMBxyz...",
       "expires_in": 3599,
       "refresh_token": "1//xxxxx...",
       "token_type": "Bearer"
     }

Step 4: Store in Database
  └─ Copy the "access_token" value
  └─ Go to Supabase Dashboard
  └─ SQL Editor → Update system_config:
     UPDATE system_config 
     SET config_value = 'ya29.a0AfH6SMBxyz...'
     WHERE config_key = 'blogger_api_key';

================================================================================
TROUBLESHOOTING
================================================================================

Blogger Publishing Fails:
  └─ Check: blogger_api_key is valid access token
  └─ Check: blogger_blog_id is correct
  └─ Token expired? Get new one from OAuth Playground
  └─ Run: /api/debug/blogger-test for detailed error

Cron Jobs Not Running:
  └─ Check: CRON_SECRET matches in Vercel Crons settings
  └─ Check: Authorization header includes "Bearer SECRET"
  └─ Check: Endpoint URL is correct
  └─ View: Dashboard → Logs tab for execution history

AI Enrichment Fails:
  └─ Check: OPENROUTER_API_KEY in Vercel env vars
  └─ Check: Account has remaining credits
  └─ Key format: starts with "sk-or-v1-"
