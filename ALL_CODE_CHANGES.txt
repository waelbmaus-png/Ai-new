================================================================================
                        CRITICAL BUG FIXED
================================================================================

ISSUE: Articles stuck at status='deduped', never reaching 'enriched' or 'published'

ROOT CAUSE:
  The enrich-and-publish cron was looking for articles with status='enriched'
  but articles never received that status during enrichment. This created an
  infinite loop where:
  - fetch-feeds creates articles with status='pending'
  - deduplicate changes to status='deduped'
  - enrich-and-publish looks for status='enriched' (never exists)
  - Articles never get enriched or published

FIX:
  Line 60 in /app/api/cron/enrich-and-publish/route.ts:
  
  BEFORE:
    .eq("status", "enriched")  // ❌ WRONG
  
  AFTER:
    .eq("status", "deduped")   // ✓ CORRECT
  
  PLUS: Added explicit status='enriched' update in enrichment step:
    .update({
      meta_description: enriched.metaDescription,
      meta_keywords: enriched.metaKeywords,
      ai_generated_labels: enriched.labels,
      summary: enriched.summary,
      status: "enriched",  // ← ADDED
    })

RESULT: Articles now follow correct pipeline:
  pending → deduped → enriched → published
